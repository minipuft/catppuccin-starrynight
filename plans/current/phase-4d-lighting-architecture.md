## Traditional Art Fundamentals

### How Artists Build Form with Light

When a painter renders a sphere, they use these distinct tonal layers:

#### The Seven Tones of Form

**1. Specular Highlight** (Lightest)
- Direct reflection of light source
- Almost pure white with slight color tint
- Smallest area, highest intensity
- Example: Bright spot on glass where sun hits

**2. Highlight / Direct Light**
- Where primary light hits the form directly
- Base color + lighter + warmer + more saturated
- Largest illuminated area
- Example: Top of a rounded surface facing sun

**3. Midtone / Local Color**
- The "true" color of the object
- What you see in neutral/diffused lighting
- Transition zone between light and shadow
- Example: Side of sphere at 45° from light

**4. Core Shadow / Form Shadow**
- Where light doesn't reach the form
- Base color + darker + cooler + less saturated
- Darkest part of the object itself
- Example: Bottom of sphere away from light

**5. Reflected Light**
- Bounce light from surroundings into shadow area
- Often has complementary color influence
- Lighter than core shadow but NEVER lighter than midtone
- Example: Ground reflection lighting underside of sphere

**6. Cast Shadow**
- Shadow the object throws onto other surfaces
- Darkest near object, lighter/softer as it extends away
- Cool temperature (opposite of light source)
- Example: Dark oval on table beneath sphere

**7. Ambient Occlusion / Contact Shadow** (Darkest)
- Where two surfaces meet/touch
- Almost black but retains subtle hue
- Defines depth and physical separation
- Example: Where sphere touches table

### Color Temperature Theory

**The Golden Rule**: Warm light creates cool shadows, cool light creates warm shadows

**Warm Light Scenario** (Sunlight):
- Light: Yellow-white (warm)
- Shadow: Blue-purple (cool)
- Reflected: Orange-pink (warm bounce)

**Cool Light Scenario** (Moonlight):
- Light: Blue-white (cool)
- Shadow: Purple-brown (warm)
- Reflected: Cyan-green (cool bounce)

### Why This Matters for UI

**Current Problem**: We're treating colors as if they ARE the lighting roles. But blue isn't "a highlight" - blue can BE highlighted or shadowed. We need to separate:
- **Material** (what color something is: blue, pink, mauve)
- **Lighting** (how light affects it: lit, shadowed, reflected)

### Layer 3: Lighting Variants (Application - HOW)

**Purpose**: How light and shadow affect each semantic role - derived from base + lighting

**Implementation Strategy**: Two approaches depending on browser support

#### Approach A: Modern CSS (Relative Colors)

**Best for**: 2023+ browsers, progressive enhancement

```scss
:root {
  // === ACCENT LIGHTING VARIANTS ===
  // Blue gets both lit and shadowed versions

  // Lit version: Lighter, warmer, more saturated
  --ui-accent-lit: oklch(
    from var(--ui-accent-base)
    calc(l + 0.15)              // +15% lightness
    calc(c * 1.2)               // +20% chroma (saturation)
    calc(h - 5deg)              // Shift toward warm
  );

  // Shadowed version: Darker, cooler, less saturated
  --ui-accent-shadowed: oklch(
    from var(--ui-accent-base)
    calc(l - 0.15)              // -15% lightness
    calc(c * 0.8)               // -20% chroma
    calc(h + 10deg)             // Shift toward cool
  );

  // Reflected version: In shadow but with ambient bounce
  --ui-accent-reflected: oklch(
    from var(--ui-accent-base)
    calc(l - 0.08)              // Slightly darker
    calc(c * 0.9)               // Slightly desaturated
    calc(h + 15deg)             // Shift toward complementary
  );

  // === STRUCTURAL LIGHTING VARIANTS ===
  --ui-structural-lit: oklch(from var(--ui-structural-base) calc(l + 0.12) calc(c * 1.15) calc(h - 8deg));
  --ui-structural-shadowed: oklch(from var(--ui-structural-base) calc(l - 0.18) calc(c * 0.75) calc(h + 12deg));

  // === EMPHASIS LIGHTING VARIANTS ===
  --ui-emphasis-lit: oklch(from var(--ui-accent-tertiary) calc(l + 0.18) calc(c * 1.25) calc(h - 10deg));
  --ui-emphasis-shadowed: oklch(from var(--ui-accent-tertiary) calc(l - 0.12) calc(c * 0.85) calc(h + 8deg));
}
```

#### Approach B: Color-Mix (Better Browser Support)

**Best for**: 2022+ browsers, including Chromium

```scss
:root {
  // === GLOBAL LIGHT PROPERTIES ===
  // These define your "lighting setup" for the entire scene
  --global-light-warm: #fffaeb;              // Warm white (yellow tint)
  --global-light-cool: #e0e8ff;              // Cool white (blue tint)
  --global-shadow-cool: #6470a0;             // Cool shadow tint (blue-purple)
  --global-shadow-warm: #8b7c72;             // Warm shadow tint (brown-purple)

  // === ACCENT LIGHTING VARIANTS (using color-mix) ===

  // Lit: Mix base color with warm light
  --ui-accent-lit: color-mix(
    in oklab,
    var(--ui-accent-base) 70%,
    var(--global-light-warm) 30%
  );

  // Shadowed: Mix base color with cool shadow
  --ui-accent-shadowed: color-mix(
    in oklab,
    var(--ui-accent-base) 60%,
    var(--global-shadow-cool) 40%
  );

  // Reflected: Mix shadowed with ambient light
  --ui-accent-reflected: color-mix(
    in oklab,
    var(--ui-accent-shadowed) 80%,
    var(--global-light-cool) 20%
  );

  // === STRUCTURAL VARIANTS ===
  --ui-structural-lit: color-mix(in oklab, var(--ui-structural-base) 75%, var(--global-light-warm) 25%);
  --ui-structural-shadowed: color-mix(in oklab, var(--ui-structural-base) 65%, var(--global-shadow-cool) 35%);

  // === EMPHASIS VARIANTS ===
  --ui-emphasis-lit: color-mix(in oklab, var(--ui-accent-tertiary) 65%, var(--global-light-warm) 35%);
  --ui-emphasis-shadowed: color-mix(in oklab, var(--ui-accent-tertiary) 70%, var(--global-shadow-cool) 30%);
}
```

#### Approach C: Fallback (Static Pre-Calculated)

**Best for**: Maximum compatibility, Spicetify safety

```scss
:root {
  // === ACCENT LIGHTING VARIANTS (hardcoded) ===
  // Calculated offline, shipped as static values
  // Blue base: #8ab5fb → lit: #b5d4ff → shadowed: #6789c8

  --ui-accent-base: var(--oklab-blue);        // #8ab5fb
  --ui-accent-base-rgb: var(--oklab-blue-rgb); // 138, 181, 251

  --ui-accent-lit: #b5d4ff;                   // Pre-calculated lighter
  --ui-accent-lit-rgb: 181, 212, 255;

  --ui-accent-shadowed: #6789c8;              // Pre-calculated darker
  --ui-accent-shadowed-rgb: 103, 137, 200;

  --ui-accent-reflected: #7a9ddb;             // Pre-calculated reflected
  --ui-accent-reflected-rgb: 122, 157, 219;

  // Mauve base: #ccb7f8 → lit: #e5d9ff → shadowed: #9b86c5
  --ui-structural-base: var(--oklab-mauve);
  --ui-structural-lit: #e5d9ff;
  --ui-structural-shadowed: #9b86c5;

  // Pink base: #f6c3e8 → lit: #ffdff5 → shadowed: #d199c8
```

### Layer 4: Global Properties (Scene - WHERE/WHEN)

**Purpose**: Scene-wide lighting settings that affect all colors uniformly

**Implementation**:
```scss
:root {
  // === LIGHTING TEMPERATURE CONTROL ===
  // 0 = cool, 0.5 = neutral, 1.0 = warm
  --global-light-temperature: 0.8;           // Warm light (default)
  --global-shadow-temperature: 0.3;          // Cool shadows (default)

  // === LIGHTING INTENSITY ===
  --global-light-intensity: 0.5;             // How strong highlights are (0-1)
  --global-shadow-intensity: 0.4;            // How deep shadows are (0-1)

  // === ATMOSPHERIC PROPERTIES ===
  --global-atmosphere-density: 0.3;          // Depth haze intensity
  --global-atmosphere-color: var(--oklab-teal); // Distance color tint

  // === MUSIC-REACTIVE MODULATION ===
  // These are set by TypeScript based on audio analysis
  --music-light-boost: 1.0;                  // Multiplier for light intensity (beat pulse)
  --music-shadow-boost: 1.0;                 // Multiplier for shadow depth
  --music-temperature-shift: 0deg;           // Hue shift based on genre/mood
}

// === LIGHTING SCENARIOS (Presets) ===

// High-energy music: Intense highlights, deep shadows
.music-energy-high {
  --global-light-intensity: 0.7;
  --global-shadow-intensity: 0.6;
  --global-light-temperature: 0.9;  // Warmer
}

// Calm music: Gentle lighting, soft shadows
.music-energy-calm {
  --global-light-intensity: 0.3;
  --global-shadow-intensity: 0.2;
  --global-light-temperature: 0.5;  // Neutral
}

// Night mode: Cool lighting
.theme-night {
  --global-light-temperature: 0.3;  // Cool
  --global-shadow-temperature: 0.7; // Warm shadows (inverse)
  --global-light-intensity: 0.4;
}
```

**Music Integration**:
```typescript

export interface LightingSettings {
  // Lighting Temperature (0-1)
  lightTemperature: number;    // 0=cool, 1=warm
  shadowTemperature: number;   // Opposite of light

  // Lighting Intensity (0-1)

  shadowIntensity: number;     // Shadow depth

  // Atmospheric Effects (0-1)
  atmosphereDensity: number;   // Depth haze
}

// Default lighting settings
export const DEFAULT_LIGHTING_SETTINGS: LightingSettings = {
  lightTemperature: 0.8,      // Warm default
  shadowTemperature: 0.3,     // Cool shadows
  lightIntensity: 0.5,        // Medium highlights
  shadowIntensity: 0.4,       // Subtle shadows
  atmosphereDensity: 0.3      // Gentle depth haze

/**
 * Apply lighting settings to CSS variables

export function applyLightingSettings(settings: LightingSettings): void {
```

## Appendix A: Color Theory Reference

### Warm vs Cool Colors

**Warm Colors** (advance toward viewer):
- Red, Orange, Yellow
- Pink, Peach, Amber
- Use for: Highlights, light sources, emphasis

**Cool Colors** (recede from viewer):
- Blue, Cyan, Teal
- Purple, Lavender, Violet
- Use for: Shadows, depth, distance

### Complementary Pairs

**For Reflected Light**:
- Blue ↔ Orange
- Red ↔ Green
- Yellow ↔ Purple

**Our Palette**:
- Blue ↔ (Yellow/Peach) ✅
- Mauve ↔ (Yellow/Green) ✅

**From Light to Dark** (establish depth):
1. Yellow (lightest warm)
2. Pink (light warm)
3. Lavender (light cool)
4. Blue (mid cool)
5. Mauve (mid warm-cool)
6. Teal (mid cool)
7. Sapphire (dark cool)
